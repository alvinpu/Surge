# Surge

**AI Unlock Checker** 是一个 Surge Mac 模块。它从本地代理和已加载的远程订阅中找到美国名称线路，通过每条线路分别访问 IPPure、ChatGPT 和 Gemini，再把符合条件的线路写进 `AI Picks` 智能策略组。适合已经有节点订阅、想让 Surge 定期维护 AI 候选线路的人。

[模块安装地址（在 Surge 中从 URL 安装）](https://raw.githubusercontent.com/alvinpu/Surge/refs/heads/main/Modules/AI-Unlock-Checker/AI-Unlock-Checker.sgmodule) · [模块定义](Modules/AI-Unlock-Checker/AI-Unlock-Checker.sgmodule) · [检测脚本](Modules/AI-Unlock-Checker/ai-check.js)

## 安装和第一次运行

1. 在 **Surge Mac** 启用脚本功能，打开一份可编辑的配置，确认订阅节点已加载。此模块已在 Surge Mac 6.13.0 验证。
2. 在配置的 `[Proxy Group]` 段准备一个专用智能组。下面是一行示例，把“节点订阅”替换成你已有的订阅策略组名称。已有专用组可沿用 `AI Picks` 或 `🔍AI Picks` 其中一个名称。模块会接管它的来源组和节点过滤条件。

   ```ini
   AI Picks = smart, include-other-group="节点订阅", evaluate-before-use=1
   ```

3. 在 Surge 的**模块**页面选择**从 URL 安装**，粘贴本页顶部的模块安装地址并启用。到**脚本**页面运行一次 `AI Unlock Scan`。
4. 打开 `AI Picks` 面板查看检测时间和入组线路，再到策略组核对成员。要让 AI 流量使用它，在现有 AI 分流规则指向的手动选择组中加入并选中 `AI Picks`。安装模块本身不会切换当前出口。

## 哪些线路会入组

| 条件 | 判断方式 |
| --- | --- |
| 名称标记为美国 | 扫描所有已加载订阅和本地代理，识别 🇺🇸、美国、美國、US、USA、United States 等标记。只有城市名的线路可能无法匹配。 |
| 美国原生 IP、风险分低于 39 | 一次 IPPure 请求同时读取 `countryCode`、`isBroadcast` 和 `fraudScore`。要求国家为 `US`、广播标记为 `false`、有效分数小于 39。住宅属性不参与筛选。 |
| ChatGPT 匿名网页通过 | 请求官网首页，检查 HTTP 200、ChatGPT 页面标题和页面标记。 |
| Gemini 匿名网页通过 | 请求官网首页，检查 HTTP 200，以及可识别的支持地区或功能标记。地区限制和验证页不计入通过。 |

每条候选策略每轮最多 **3 个请求**，分别指定该策略为出口，单项超时 **15 秒**。模块不登录账号、不带浏览器 Cookie，也不重试、跟随跳转或另做测速。多条线路共用出口 IP 时，各自符合条件就各自入组。

匿名检测确认的是当时的网页响应。一次超时、遇到验证页或网页改版都可能让日常可用的线路落选。它不能验证登录后的对话质量或预测账号风控。39 分是本模块选择的门槛；IPPure 的评分依据包括历史记录和 IP 段推断。[IPPure 评分说明](https://ippure.com/faq) · [IPPure 字段说明](https://ippure.com/MyIP-Info-API)

## 什么时候运行

- 每周三、周日按 Mac 当地时间 **06:30** 启动，**07:00** 是补位时段。Mac 和 Surge 需要能够运行脚本。
- 两台 Mac 共用同一份可编辑的 iCloud 配置时，模块在配置里记录本轮启动时间，上次成功写入的 Mac 优先运行。另一台读到本轮记录就跳过。如果主机没有启动本轮，在线的另一台可在补位时段接手。iCloud 同步延迟时仍有重复启动的可能。
- iPhone 可以加载同步后的配置并使用策略组。定时检测和写回由 Mac 执行，两台 Mac 都关机时，手机可继续使用最后同步的成员。

## 看懂运行结果

| 看到的结果 | 实际含义 |
| --- | --- |
| 两家通过的数量高于入组数量 | 一些线路满足匿名访问条件，但风险分、美国原生属性或 IP 查询结果未满足入组条件。 |
| `HTTP 302 跳转 → www.google.com/sorry/index` | 这是跳转记录的示例。面板显示服务、目标域名和路径，省略查询参数及片段。脚本只记录本次响应。 |
| 本轮已检测或已启动，跳过 | 同一轮重复触发时直接结束，包括手动运行和补位任务。 |
| 本轮零条合格 | 保留原组成员。此时组里的线路来自之前的配置，不能当作本轮已验证。 |
| 提示目标组缺失、重复或配置不可编辑 | 检查目标组名称是否唯一、是否位于可写的策略组段，以及是否为模块可维护的 smart 组。使用独立订阅地址或手工固定成员的组，应另建专用组。 |
